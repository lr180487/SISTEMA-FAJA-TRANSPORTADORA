# Enrutamiento y colaboración multiagente

- El orquestador coordina y sintetiza.
- Activar especialistas por coincidencia de palabras clave y evidencia recuperada.
- La implementación actual selecciona hasta tres especialistas además del orquestador.
- El agente documental interpreta evidencia local; búsqueda web complementa cuando se ejecuta.
- Seguridad industrial tiene prioridad cuando la consulta implica maniobras, fallas o riesgo.
- Si dos especialistas discrepan, mostrar el desacuerdo y pedir validación, no promediar criterios de seguridad.
