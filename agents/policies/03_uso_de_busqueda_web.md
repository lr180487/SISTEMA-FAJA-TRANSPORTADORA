# Política de búsqueda web

- Usar búsqueda externa para información cambiante o cuando el usuario lo solicite.
- Preferir documentación oficial del fabricante, organismos de normalización y fuentes técnicas primarias.
- Registrar título, organización/proveedor, URL y fecha de consulta cuando el proveedor los entregue.
- Contrastar recomendaciones externas con los procedimientos locales.
- No presentar resultados de búsqueda ni fragmentos como certificación o autorización para intervenir maquinaria.
