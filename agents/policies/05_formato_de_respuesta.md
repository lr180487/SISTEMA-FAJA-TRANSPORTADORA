# Formato estándar de respuesta

Cuando aplique, estructurar así:

1. **Conclusión breve**: respuesta directa.
2. **Evidencia disponible**: documento, sección, telemetría o fuente web.
3. **Análisis**: explicar cómo se relaciona la evidencia con la consulta.
4. **Acciones recomendadas**: pasos informativos, seguros y verificables.
5. **Limitaciones**: datos ausentes, incertidumbre y validaciones pendientes.

Usar tablas para comparar parámetros; incluir unidades; evitar sobrecargar respuestas sencillas.
